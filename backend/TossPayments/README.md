# 이분 - 쉽게 서비스에 토스페이먼츠 연동 과정

> 해당 폴더에서는 사내에서 토스페이먼츠 결제를 연동하기 위해 필요한 내용을 정리합니다.

<br>

# 📍 요약

### ✔️ 프로젝트 기간

- 2024-11-04 ~ 2024-11-29 (한달)

### ✔️ 역할

- 토스페이먼츠 개발 일정 리드 및 백엔드 개발 담당

### ✔️ 문제점 & 목표

- 쉽게 서비스는 업무 편의툴이지만 B2B SaaS 플랫폼으로 간주되어 `기업 내부에서 결재/결제 프로세스가 오래걸리는 문제`가 있음.
- 실제 계약 단계부터 결제까지 과정을 줄이기 위해 빠른 결제 시스템 연동을 통해 24년도가 가기 전에 결제 1건 이상을 달성하는 것이 목표.
